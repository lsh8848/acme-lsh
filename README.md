## VPS本地IP的acme证书申请一键脚本
-------------------------------------
### 一键脚本
```
bash <(curl -Ls https://raw.githubusercontent.com/lsh8848/acme-lsh/main/acme.sh)
```
或者
```
bash <(wget -qO- https://raw.githubusercontent.com/lsh8848/acme-lsh/main/acme.sh)
```
---------------------------------------
#### 功能与特点：
1：支持纯IPV4、纯IPV6、双栈VPS

2：支持80端口模式与DNS API模式，支持单域名与泛域名

3：支持Cloudflare/腾讯DNSPod/阿里Aliyun托管解析平台的DNS API申请

4：查询、撤销并删除当前已申请的域名证书 

5：手动一键或者指定续期域名证书

6：两个证书文件存放在root/lshca目录中

7：支持多域名自动续期

#### 注意：使用80端口模式时，会强制释放80端口，申请证书时先停止nginx，成功后重启nginx

---------------------------------------------

## 自动续期使用说明（对应菜单4）

### 一、怎么用

1. 先到 **菜单1** 把域名证书申请好（80端口模式或DNS API模式都可以）。

2. 进入 **菜单4「批量域名自动续期配置」**。

3. 按提示一次输入多个域名，支持三种写法：

   ```
   a.example.com
   b.example.com
   c.example.com
   ```

   或一行内用空格/逗号分隔：

   ```
   a.example.com b.example.com, c.example.com
   ```

   泛域名写 `*.example.com`（脚本会自动换算成 acme.sh 记录里的 `example.com`）。

4. 输入完成后**在空行按回车**结束。什么都不输入直接回车，则对当前全部已申请证书生效。

5. 脚本会列出每个域名的剩余天数和验证方式，确认后输入 `1` 写入配置。

写入后脚本会做两件事：

- 把续期钩子写进每个证书自己的配置（`~/.acme.sh/<域名>_ecc/<域名>.conf`）；
- 安装 root 的 crontab：每天 03:00 执行一次 `acme.sh --cron`。

### 二、到期前多久续期

Let's Encrypt 证书有效期 90 天，acme.sh 上游默认在**剩余 30 天**时才真正换证
（`DEFAULT_RENEW=30`）。所以任务是"每天检查、临近到期自动换"，不是到期当天才动手。

用 **菜单2** 可以查看每个域名的 `Renew` 时间点，即下次真正换证的时刻。

### 三、80端口被 nginx 占用怎么办

不用管，也不会杀掉 nginx 之外的服务。机制是 acme.sh 官方的钩子：

| 钩子        | 时机                             | 做什么                        |
| ----------- | -------------------------------- | ----------------------------- |
| `pre-hook`  | 本次确实要换证，验证开始前       | 停止 nginx，并留一个标记文件  |
| `post-hook` | 验证结束（无论成功失败）         | 只要停过 nginx 就把它拉起来   |
| `reloadcmd` | 新证书安装到 `/root/lshca/` 之后 | 再次确认 nginx 已运行（幂等） |

因为钩子随证书保存在它的续期配置里，所以**以后每次自动续期都由 acme.sh 自己完成停/启**，
不需要外部脚本在正确的时机介入。DNS API 模式的证书不占80端口，钩子在那里是空操作。

如果80端口被 nginx 以外的进程占用，菜单4在配置阶段会明确提示，并建议改用DNS API模式。

### 四、日常检查

```bash
crontab -l                       # 看自动续期任务是否存在
cat ~/.acme.sh/acme-lsh-renew.log   # 看每天续期的实际输出
~/.acme.sh/acme.sh --list        # 看所有证书与下次续期时间
ls -l /root/lshca/               # 看已安装的证书文件
```

**菜单3** 是手动一键续期（立即对全部域名跑一次），适合刚配置完想验证一次的场景。

### 五、注意

- 自动续期依赖 `~/.acme.sh` 里的续期配置，请不要手工改动该目录下的 `<域名>.conf`。
- DNS API 模式要能续期，前提是申请时填的 API Key 已被 acme.sh 存入 `~/.acme.sh/account.conf`
  （`SAVED_CF_Key` / `SAVED_DP_Id` 等形式）。更换密钥后请重新申请一次或更新该文件。
- 卸载用 **菜单5**，它会同时清理证书记录、crontab 任务和 `/root/lshca` 证书文件。
